Stressed LogIt v1.2 QA checklist
=================================

Automated checks performed:
- Inline browser JavaScript syntax checked with Node.
- Firebase Cloud Function JavaScript syntax checked with Node.
- Required package paths verified.
- Manifest icon references verified.
- Header uses an embedded SVG and has no external header-image dependency.
- Existing Firebase project configuration retained.
- Existing Firestore path users/{uid}/entries/{entryId} retained.
- No Firestore rules file included.
- Existing localStorage key unwind-entries-v1 retained.
- Existing entries without a status are normalized to active/Working on it.
- ZIP archive integrity verified.

Manual checks recommended after upload:
1. Sign in with Google on the authorized GitHub Pages domain.
2. Confirm an older Firestore entry appears in Working list.
3. Log a new entry and change its status.
4. Try search, category, date, status, and sorting controls.
5. Open Patterns and change the date range and trend point grouping.
6. Confirm the secure AI function after OPENAI_API_KEY is deployed.
